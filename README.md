# LostLines - Campus Lost & Found Management System

LostLines is a web-based lost and found management system for college students. It helps users report, search, filter, update, and manage lost or found items inside a campus.

## Features

- Login and Register UI
- Add lost/found items
- Edit item details
- Delete item records
- Search by item name or location
- Filter by status: Lost or Found
- Sort by newest or oldest
- Category and priority selection
- Statistics dashboard
- Recently added items
- Dark mode with persistence
- Local Storage support
- CSV export
- Responsive design
